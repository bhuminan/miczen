พีชคณิตพื้นฐานและเอกลักษณ์

บทนี้เป็นสะพานจากการคำนวณตัวเลขไปสู่การคิดด้วยสัญลักษณ์ นักเรียนจะฝึกมองนิพจน์ให้เห็นโครงสร้าง เช่น พจน์ที่คล้ายกัน วงเล็บ ตัวร่วม และเอกลักษณ์สำคัญที่ใช้คิดเร็วในโจทย์แข่งขัน

ระดับ ม.ต้นสอวน. คอมสอบเข้า ม.4Interactive + Printable

1. เป้าหมายและคำศัพท์สำคัญ

เป้าหมายการเรียนรู้

  • รู้จักพจน์ ตัวแปร สัมประสิทธิ์ และพจน์ที่คล้ายกัน
  • กระจายวงเล็บและดึงตัวร่วมได้ถูกต้อง
  • ใช้เอกลักษณ์พีชคณิตสำคัญเพื่อจัดรูปและคิดเร็ว
  • ระวังเครื่องหมายลบและพจน์กลางในสูตรกำลังสอง
  • เชื่อมการจัดรูปนิพจน์กับการลดขั้นตอนในโปรแกรม

2. สูตรและกฎที่ต้องแม่น

หลักสำคัญ: พีชคณิตไม่ใช่การเดาสูตร แต่คือการรักษาค่าเดิมของนิพจน์ไว้ แล้วเปลี่ยนรูปให้อ่านง่าย คิดเร็ว หรือแก้โจทย์ต่อได้สะดวกขึ้น

พจน์ที่คล้ายกัน

รวมได้เมื่อมีตัวแปรและเลขชี้กำลังเหมือนกัน

3x + 5x = 8x แต่ 3x + 5y รวมกันไม่ได้

การกระจาย

a(b+c) = ab + ac

เป็นกฎหลักของการเปิดวงเล็บ

ลบหน้าวงเล็บ

-(a-b) = -a + b

ข้อสอบชอบหลอกเครื่องหมาย

การดึงตัวร่วม

ab + ac = a(b+c)

เป็นการย้อนกลับของการกระจาย

กำลังสองของผลบวก

(a+b)2 = a2 + 2ab + b2

พจน์กลาง 2ab ห้ามลืม

กำลังสองของผลลบ

(a-b)2 = a2 - 2ab + b2

พจน์กลางติดลบ

ผลต่างกำลังสอง

(a+b)(a-b) = a2 - b2

ใช้คิดเร็วและแยกตัวประกอบ

ผลคูณสองวงเล็บ

(x+a)(x+b)=x2+(a+b)x+ab

ผลบวกของ a,b เป็นสัมประสิทธิ์ x; ผลคูณเป็นค่าคงที่

3. ตัวอย่างพร้อมวิธีคิดทีละขั้น

ตัวอย่างที่ 1: รวมพจน์และจัดรูป

โจทย์: จัดรูป 4x + 3 - 2x + 7

  1. รวมพจน์ที่มี x: 4x - 2x = 2x
  2. รวมค่าคงที่: 3 + 7 = 10
  3. คำตอบคือ 2x + 10

ตอบ: 2x + 10

ตัวอย่างที่ 2: เปิดวงเล็บที่มีเครื่องหมายลบ

โจทย์: จัดรูป 5(x-2) - 3(x+4)

  1. กระจายวงเล็บแรก: 5x - 10
  2. กระจายวงเล็บที่สองพร้อมลบหน้า: -3x - 12
  3. รวมได้ 2x - 22

ตอบ: 2x - 22

ตัวอย่างที่ 3: ใช้เอกลักษณ์กำลังสอง

โจทย์: กระจาย (2x + 5)2

  1. ให้ a = 2x และ b = 5
  2. ใช้ (a+b)2 = a2 + 2ab + b2
  3. ได้ 4x2 + 20x + 25

ตอบ: 4x2 + 20x + 25

ตัวอย่างที่ 4: คิดเร็วด้วยผลต่างกำลังสอง

โจทย์: หาค่า 102 × 98

  1. เขียนเป็น (100+2)(100-2)
  2. ใช้ (a+b)(a-b)=a2-b2
  3. ได้ 10000 - 4 = 9996

ตอบ: 9996

4. จุดหลอกข้อสอบที่ต้องระวัง

(a+b)^2 ไม่เท่ากับ a^2+b^2
ต้องมีพจน์กลาง 2ab เช่น (x+3)^2 = x^2+6x+9
ลบหน้าวงเล็บต้องเปลี่ยนเครื่องหมายทุกพจน์
-(x-5) = -x+5 ไม่ใช่ -x-5
รวมพจน์ได้เฉพาะพจน์ที่คล้ายกัน
2x+3y รวมเป็น 5xy ไม่ได้
คูณสองวงเล็บต้องคูณครบทุกคู่
(x+2)(x+3) มี 4 ผลคูณย่อย
ดึงตัวร่วมต้องเหลือพจน์ครบ
6x+12 = 6(x+2) ไม่ใช่ 6x(1+2)
ผลต่างกำลังสองต้องเป็นผลบวกคูณผลลบ
a^2-b^2=(a-b)(a+b) แต่ a^2+b^2 แยกแบบนี้ไม่ได้ในจำนวนจริง

5. มุมคิดแบบโปรแกรมเมอร์

การจัดรูปนิพจน์ช่วยให้โปรแกรมทำงานน้อยลงและทำให้เห็น pattern เช่น แทนที่จะคำนวณกำลังสองสองครั้งใน loop เราอาจจัดรูปก่อนแล้วใช้สูตรที่ง่ายกว่า

แนวคิดการใช้แบบโปรแกรมเมอร์
นิพจน์ 2x+3expression ที่ต้องแทนค่า x ก่อนคำนวณ
จัดรูปก่อนคำนวณลดจำนวน operation และลดโอกาส overflow ในบางภาษา
(n+1)2-n2 = 2n+1ใช้หา pattern แทนการคำนวณซ้ำใน loop
a2-b2ใช้คิดเร็วเมื่อจำนวนใกล้กัน เช่น 1002×998
สังเกต: ในโจทย์ สอวน. คอม การมอง pattern อย่าง (n+1)2-n2=2n+1 ช่วยเปลี่ยนโจทย์ที่ดูเหมือนต้องวนซ้ำให้กลายเป็นสูตรตรงได้

6. แบบฝึกหัด Interactive

พิมพ์คำตอบแล้วกดตรวจคำตอบ หากติดให้กด Hint ก่อนเปิดเฉลย เพื่อฝึกคิดเองทีละขั้น

ระดับง่าย: รู้จักพจน์ สัมประสิทธิ์ และพจน์ที่คล้ายกัน

E1

ในนิพจน์ 7x สัมประสิทธิ์ของ x คือเท่าใด

Hint: สัมประสิทธิ์คือตัวเลขที่คูณอยู่กับตัวแปร
เฉลย: ใน 7x มีตัวเลข 7 คูณกับ x ดังนั้นสัมประสิทธิ์คือ 7
คำตอบ: 7
E2

ในนิพจน์ -5a สัมประสิทธิ์ของ a คือเท่าใด

Hint: เครื่องหมายลบเป็นส่วนหนึ่งของสัมประสิทธิ์
เฉลย: -5a = (-5)×a ดังนั้นสัมประสิทธิ์คือ -5
คำตอบ: -5
E3

จงรวมพจน์ 3x + 5x

Hint: พจน์ที่มีตัวแปรและเลขชี้กำลังเหมือนกันรวมกันได้
เฉลย: 3x + 5x = (3+5)x = 8x
คำตอบ: 8x
E4

จงรวมพจน์ 9y - 4y

Hint: รวมเฉพาะสัมประสิทธิ์
เฉลย: 9y - 4y = (9-4)y = 5y
คำตอบ: 5y
E5

จงรวมพจน์ 2a + 3b + 5a

Hint: รวมเฉพาะพจน์ a เข้าด้วยกัน
เฉลย: 2a + 5a = 7a ส่วน 3b รวมกับ a ไม่ได้ จึงได้ 7a + 3b
คำตอบ: 7a+3b
E6

จงกระจาย 4(x + 3)

Hint: คูณ 4 เข้าไปทั้งสองพจน์ในวงเล็บ
เฉลย: 4(x+3)=4x+4×3=4x+12
คำตอบ: 4x+12
E7

จงกระจาย -2(x - 5)

Hint: ระวังลบคูณลบได้บวก
เฉลย: -2(x-5)=(-2)x+(-2)(-5)=-2x+10
คำตอบ: -2x+10
E8

จงจัดรูป 3(x+2)+x

Hint: กระจายก่อน แล้วรวมพจน์ที่คล้ายกัน
เฉลย: 3(x+2)+x = 3x+6+x = 4x+6
คำตอบ: 4x+6
E9

จงจัดรูป 5m - 2m + 7

Hint: รวมเฉพาะพจน์ที่มี m
เฉลย: 5m-2m=3m ดังนั้นได้ 3m+7
คำตอบ: 3m+7
E10

จงหาค่า 2x + 3 เมื่อ x = 4

Hint: แทน x ด้วย 4
เฉลย: 2x+3 = 2(4)+3 = 8+3 = 11
คำตอบ: 11
