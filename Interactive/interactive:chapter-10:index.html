1. เป้าหมายและคำศัพท์สำคัญ

2. สูตรและกฎที่ต้องแม่น

หลักสำคัญ: สมการกำลังสองควรจัดให้อยู่ในรูป ax2+bx+c=0 ก่อนเสมอ จากนั้นเลือกวิธีที่เหมาะที่สุด: แยกตัวประกอบถ้าทำได้ง่าย ใช้สูตรกำลังสองเมื่อแยกยาก และใช้ discriminant เพื่อตรวจจำนวนรากจริง

รูปมาตรฐานของสมการกำลังสอง

ax2 + bx + c = 0, a ≠ 0

ต้องจัดทุกพจน์ไว้ฝั่งเดียวก่อนเลือกวิธีแก้

สมบัติผลคูณเป็นศูนย์

AB = 0 -> A = 0 หรือ B = 0

ใช้หลังแยกตัวประกอบแล้วเท่านั้น

แยกไตรนามพื้นฐาน

x2 + (p+q)x + pq = (x+p)(x+q)

มองหาคู่จำนวนที่บวกและคูณตรงเงื่อนไข

ผลต่างกำลังสอง

a2 - b2 = (a-b)(a+b)

เช่น x^2-9=(x-3)(x+3)

กำลังสองสมบูรณ์

a2 ± 2ab + b2 = (a±b)2

ช่วยดูรากซ้ำและจัดรูปเร็ว

สูตรกำลังสอง

x = (-b ± √(b2 - 4ac)) / 2a

ใช้เมื่อแยกตัวประกอบยากหรือไม่ได้คำตอบเป็นจำนวนเต็ม

Discriminant

D = b2 - 4ac

D>0 มี 2 รากจริง, D=0 มีรากซ้ำ, D<0 ไม่มีรากจริง

ความสัมพันธ์ของราก

ผลบวก = -b/a, ผลคูณ = c/a

ใช้หาค่าพารามิเตอร์หรือคิดเร็วในข้อสอบ

3. ตัวอย่างพร้อมวิธีคิดทีละขั้น

ตัวอย่างที่ 1: แยกตัวประกอบพื้นฐาน

โจทย์: แก้สมการ x2 - 5x + 6 = 0

  1. ต้องการคู่ที่คูณได้ 6 และบวกได้ -5
  2. คู่ที่เหมาะคือ -2 และ -3
  3. จึงได้ (x-2)(x-3)=0

คำตอบ: x=2 หรือ x=3

ตัวอย่างที่ 2: อย่าหารด้วยตัวแปรทันที

โจทย์: แก้สมการ x2 - 4x = 0

  1. ดึงตัวร่วม x: x(x-4)=0
  2. แยกเป็น x=0 หรือ x-4=0
  3. ถ้าหารด้วย x ตั้งแต่แรก จะทำให้คำตอบ x=0 หายไป

คำตอบ: x=0 หรือ x=4

ตัวอย่างที่ 3: ใช้สูตรกำลังสอง

โจทย์: แก้สมการ x2 + 4x + 1 = 0

  1. a=1, b=4, c=1
  2. D=b2-4ac=16-4=12
  3. x=(-4±√12)/2=-2±√3

คำตอบ: x=-2±√3

ตัวอย่างที่ 4: ความสัมพันธ์ของราก

โจทย์: สมการ x2 - kx + 24 = 0 มีราก 6 และอีกหนึ่งรากเป็นจำนวนเต็มบวก จงหา k

  1. ผลคูณของรากคือ 24
  2. เมื่อรากหนึ่งคือ 6 อีกรากคือ 4
  3. ผลบวกของรากคือ 10 ดังนั้น k=10

คำตอบ: k=10

5. มุมคิดแบบโปรแกรมเมอร์

สมการกำลังสองเชื่อมกับการตรวจจำนวนกำลังสองสมบูรณ์ การคำนวณ sqrt แบบปัดเศษลง และการแยกกรณีด้วยเงื่อนไข ซึ่งเป็นแนวคิดพื้นฐานของโจทย์ สอวน. คอม

แนวคิดความหมาย
perfect square testตรวจว่า n เป็นกำลังสองสมบูรณ์หรือไม่ เช่น floor(sqrt(n))^2 == n
branching by Dใช้ค่า D เพื่อเลือกกรณี: 2 รากจริง, รากซ้ำ หรือไม่มีรากจริง
brute force rootsเมื่อต้องการรากจำนวนเต็ม อาจลองตัวหารของ c อย่างเป็นระบบ
growth of n^2กำลังสองโตเร็ว ใช้กับโจทย์หา n ต่ำสุดที่ n^2 เกินค่าหนึ่ง
สังเกต: ในโจทย์คอมพิวเตอร์ คำว่า perfect square, floor(sqrt(n)) หรือจำนวนเต็มที่ทำให้ x2 อยู่ในช่วงหนึ่ง มักเป็นสมการหรืออสมการกำลังสองที่ซ่อนอยู่
