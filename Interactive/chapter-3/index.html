เลขยกกำลัง (Exponents)

บทนี้ทำให้นักเรียนเข้าใจว่าเลขยกกำลังไม่ใช่แค่สูตรจำ แต่เป็นภาษาของการเติบโตแบบทวีคูณ การลดรูปจำนวนขนาดใหญ่ การคิดแบบฐานสอง และการวิเคราะห์จำนวนรอบของขั้นตอนวิธีในคอมพิวเตอร์

ระดับ ม.ต้นสอวน. คอมสอบเข้า ม.4Interactive + Printable

1. เป้าหมายและคำศัพท์สำคัญ

เป้าหมายการเรียนรู้

  • เข้าใจความหมายของฐานและเลขชี้กำลัง
  • ใช้กฎเลขยกกำลังได้ถูกต้อง
  • ระวังความต่างระหว่าง (-a)^n และ -a^n
  • เชื่อมเลขยกกำลังกับ pattern, binary, loop และ modulo

2. สูตรและกฎที่ต้องแม่น

หลักจำสั้น ๆ: คูณ = บวกชี้กำลัง, หาร = ลบชี้กำลัง, ซ้อน = คูณชี้กำลัง แต่ต้องเป็นฐานเดียวกันหรืออยู่ในรูปที่แปลงฐานได้ก่อน

ความหมายพื้นฐาน
a^n = a x a x ... x a (ทั้งหมด n ตัว)
a คือฐาน (base), n คือเลขชี้กำลัง (exponent)
คูณฐานเดียวกัน
a^m x a^n = a^(m+n)
ฐานเหมือนกัน คูณกัน -> บวกเลขชี้กำลัง
หารฐานเดียวกัน
a^m / a^n = a^(m-n), a != 0
ฐานเหมือนกัน หารกัน -> ลบเลขชี้กำลัง
กำลังซ้อนกำลัง
(a^m)^n = a^(mn)
เลขชี้กำลังซ้อนกัน -> คูณเลขชี้กำลัง
กระจายกำลัง
(ab)^n = a^n b^n และ (a/b)^n = a^n/b^n
ยกกำลังให้ทุกตัวในวงเล็บ
กำลังศูนย์
a^0 = 1, เมื่อ a != 0
ห้ามใช้กับ 0^0 ในระดับนี้ ให้ถือว่าไม่กำหนด
กำลังลบ
a^-n = 1/a^n, เมื่อ a != 0
เลขชี้กำลังลบไม่ได้แปลว่าค่าติดลบ
จำนวนลบยกกำลัง
(-a)^even เป็นบวก, (-a)^odd เป็นลบ
วงเล็บสำคัญมาก: (-3)^2 != -3^2

3. ตัวอย่างพร้อมวิธีคิดทีละขั้น

ตัวอย่างที่ 1: ใช้กฎคูณและหารฐานเดียวกัน

โจทย์: ลดรูป 2^7 x 2^3 / 2^4

รวมด้านบนก่อน: 2^7 x 2^3 = 2^10
หารด้วย 2^4 จึงได้ 2^(10-4) = 2^6
2^6 = 64
คำตอบ: 64
ตัวอย่างที่ 2: แปลงฐานก่อนคำนวณ

โจทย์: คำนวณ 8^4 / 16^2

8 = 2^3 ดังนั้น 8^4 = (2^3)^4 = 2^12
16 = 2^4 ดังนั้น 16^2 = (2^4)^2 = 2^8
2^12 / 2^8 = 2^4 = 16
คำตอบ: 16
ตัวอย่างที่ 3: เครื่องหมายลบกับวงเล็บ

โจทย์: เปรียบเทียบ (-4)^2 และ -4^2

(-4)^2 = (-4)(-4) = 16
-4^2 = -(4^2) = -16
ดังนั้นสองค่านี้ไม่เท่ากัน
คำตอบ: (-4)^2 = 16 แต่ -4^2 = -16
ตัวอย่างที่ 4: แนวคิดคอมพิวเตอร์

โจทย์: หาค่า k น้อยที่สุดที่ทำให้ 2^k >= 500

2^8 = 256 ยังไม่ถึง 500
2^9 = 512 ถึง 500 แล้ว
ดังนั้น k = 9
คำตอบ: 9

4. จุดหลอกข้อสอบที่ต้องระวัง

a^0 = 1 ใช้ได้เมื่อ a != 0
0^0 ไม่ควรสรุปว่าเท่ากับ 1 ในบริบท ม.ต้น
เลขชี้กำลังลบไม่ใช่จำนวนลบ
2^-3 = 1/8 ไม่ใช่ -8
วงเล็บเปลี่ยนคำตอบ
(-3)^2 = 9 แต่ -3^2 = -9
ห้ามบวกเลขชี้กำลังเมื่อฐานต่างกัน
2^3 x 3^3 = (2x3)^3 = 6^3 แต่ 2^3 x 3^4 รวมไม่ได้โดยตรง
อย่ากระจายกำลังข้ามการบวก
(a+b)^2 ไม่เท่ากับ a^2 + b^2

5. มุมคิดแบบโปรแกรมเมอร์

เลขยกกำลัง โดยเฉพาะฐาน 2 ปรากฏในคอมพิวเตอร์บ่อยมาก เพราะข้อมูลดิจิทัลใช้ระบบฐานสอง เช่น 2^10 = 1024 ซึ่งใกล้กับ 1,000 จึงเห็นหน่วยอย่าง KB, MB, GB ในบริบทคอมพิวเตอร์

แนวคิดคณิตศาสตร์เชื่อมกับคอมพิวเตอร์
2^nขนาดข้อมูล การแบ่งครึ่ง binary search
เลขชี้กำลังลบส่วนกลับ ความน่าจะเป็นเล็ก ๆ
เลขหลักหน่วยเป็นคาบmodular arithmetic และ pattern
หาค่า k ที่ 2^k เกิน nจำนวนรอบของ loop ที่หารครึ่งซ้ำ ๆ
สังเกต: ถ้าโจทย์ถามจำนวนรอบที่หารครึ่งซ้ำ ๆ มักเกี่ยวกับกำลังของ 2 และค่า log แบบไม่ต้องใช้เครื่องคิดเลข

6. แบบฝึกหัด Interactive

พิมพ์คำตอบแล้วกดตรวจคำตอบ หากติดให้กด Hint ก่อนเปิดเฉลย เพื่อฝึกคิดเองทีละขั้น

ระดับง่าย: เช็กความเข้าใจพื้นฐาน

E1คำนวณ 2^5

คำใบ้: 2^5 หมายถึง 2 คูณกัน 5 ตัว
เฉลย: 2^5 = 2 x 2 x 2 x 2 x 2 = 32
E2คำนวณ 5^0

คำใบ้: จำนวนที่ไม่เป็นศูนย์ ยกกำลัง 0 ได้ 1
เฉลย: 5^0 = 1 เพราะ a^0 = 1 เมื่อ a != 0
E3เขียน 10^-3 เป็นเศษส่วนอย่างง่าย

คำใบ้: เลขชี้กำลังลบให้กลับเป็นส่วนกลับ
เฉลย: 10^-3 = 1/10^3 = 1/1000 = 0.001
E4คำนวณ (-3)^2

คำใบ้: วงเล็บทำให้ฐานคือ -3 ทั้งจำนวน
เฉลย: (-3)^2 = (-3)(-3) = 9
E5คำนวณ -3^2

คำใบ้: ต้องยกกำลัง 3 ก่อน แล้วจึงใส่เครื่องหมายลบหน้า
เฉลย: -3^2 = -(3^2) = -9
E6คำนวณ 2^3 x 2^4

คำใบ้: ฐานเท่ากันและคูณกัน ให้บวกเลขชี้กำลัง
เฉลย: 2^3 x 2^4 = 2^(3+4) = 2^7 = 128
E7คำนวณ 7^6 / 7^2

คำใบ้: ฐานเท่ากันและหารกัน ให้ลบเลขชี้กำลัง
เฉลย: 7^6 / 7^2 = 7^(6-2) = 7^4 = 2401
E8คำนวณ (3^2)^3

คำใบ้: กำลังซ้อนกำลัง ให้คูณเลขชี้กำลัง
เฉลย: (3^2)^3 = 3^(2x3) = 3^6 = 729
E9คำนวณ (2 x 5)^3

คำใบ้: (ab)^n = a^n b^n หรือคิด 10^3 ก็ได้
เฉลย: (2 x 5)^3 = 10^3 = 1000
E10คำนวณ (6/2)^4

คำใบ้: ลดเศษส่วนในวงเล็บก่อน
เฉลย: (6/2)^4 = 3^4 = 81
E11เขียน 450000 ในรูป a x 10^n เมื่อ 1 <= a < 10

คำใบ้: เลื่อนจุดทศนิยมให้เหลือตัวหน้าอยู่ระหว่าง 1 ถึง 10
เฉลย: 450000 = 4.5 x 100000 = 4.5 x 10^5
E12เขียน 0.00072 ในรูป a x 10^n เมื่อ 1 <= a < 10

คำใบ้: จำนวนเล็กกว่า 1 จะได้เลขชี้กำลังติดลบ
เฉลย: 0.00072 = 7.2 x 10^-4

ระดับปานกลาง: ใช้กฎหลายตัวร่วมกัน

M1ลดรูป x^3 x x^5 / x^2

คำใบ้: รวมเลขชี้กำลังก่อน แล้วลบเลขชี้กำลังจากตัวส่วน
เฉลย: x^3 x x^5 / x^2 = x^(3+5-2) = x^6
M2ลดรูป (2a^3b)^2

คำใบ้: ยกกำลังให้ทุกตัวในวงเล็บ
เฉลย: (2a^3b)^2 = 2^2 a^(3x2) b^2 = 4a^6b^2
M3คำนวณ 3^8 / 9^2

คำใบ้: เปลี่ยน 9 เป็น 3^2 ก่อน
เฉลย: 9^2 = (3^2)^2 = 3^4 ดังนั้น 3^8 / 9^2 = 3^8 / 3^4 = 3^4 = 81
M4คำนวณ 16^3 / 8^4

คำใบ้: เปลี่ยนเป็นฐาน 2 ทั้งหมด
เฉลย: 16^3 = (2^4)^3 = 2^12 และ 8^4 = (2^3)^4 = 2^12 ดังนั้นคำตอบคือ 1
M5ลดรูป 5^n x 25 ให้อยู่ในรูปกำลังของ 5

คำใบ้: 25 = 5^2
เฉลย: 5^n x 25 = 5^n x 5^2 = 5^(n+2)
M6หา n เมื่อ 2^n = 64

คำใบ้: 64 คือ 2 คูณตัวเองกี่ครั้ง
เฉลย: 64 = 2^6 ดังนั้น n = 6
M7จำนวนใดมากกว่า: 3^4 หรือ 4^3

คำใบ้: คำนวณหรือเปรียบเทียบโดยตรง
เฉลย: 3^4 = 81 และ 4^3 = 64 ดังนั้น 3^4 มากกว่า
M8คำนวณ (10^3)^2 / 10^4

คำใบ้: กำลังซ้อนกำลังก่อน แล้วหารฐานเดียวกัน
เฉลย: (10^3)^2 / 10^4 = 10^6 / 10^4 = 10^2 = 100
M9คำนวณ (-2)^5 + (-2)^4

คำใบ้: กำลังคี่ของจำนวนลบเป็นลบ กำลังคู่เป็นบวก
เฉลย: (-2)^5 = -32 และ (-2)^4 = 16 ดังนั้นผลรวม = -16
M10ถ้า 2^a = 8 และ 3^b = 81 จงหา a + b

คำใบ้: เขียน 8 และ 81 เป็นกำลัง
เฉลย: 8 = 2^3 จึง a = 3 และ 81 = 3^4 จึง b = 4 ดังนั้น a+b = 7

ระดับยาก: สังเกตแพตเทิร์นและแปลงโจทย์

H1หาเลขหลักหน่วยของ 7^2026

คำใบ้: เลขหลักหน่วยของ 7^n มีคาบ 4: 7, 9, 3, 1
เฉลย: 2026 หาร 4 เหลือ 2 จึงใช้ตำแหน่งที่ 2 ของคาบ 7,9,3,1 คำตอบคือ 9
H2หาเลขหลักหน่วยของ 3^100 + 2^100

คำใบ้: ดูคาบเลขหลักหน่วยของ 3^n และ 2^n
เฉลย: 3^100 มีหลักหน่วย 1 และ 2^100 มีหลักหน่วย 6 รวมได้ 7
H3หา x เมื่อ 2^(x+1) + 2^x = 24

คำใบ้: ดึง 2^x เป็นตัวร่วม
เฉลย: 2^(x+1) + 2^x = 2x2^x + 2^x = 3x2^x = 24 จึง 2^x = 8 และ x = 3
H4ถ้า a = 2^5 x 3^2 และ b = 2^3 x 3^4 จงหา ห.ร.ม. ของ a และ b

คำใบ้: ห.ร.ม. ใช้เลขชี้กำลังที่น้อยกว่าในแต่ละฐานเฉพาะ
เฉลย: ห.ร.ม. = 2^min(5,3) x 3^min(2,4) = 2^3 x 3^2 = 8 x 9 = 72
H5ลดรูป ((x^-2 y^3)^2) / (x y^-1)

คำใบ้: ทำกำลังด้านบนก่อน แล้วหารด้วย x y^-1
เฉลย: (x^-2 y^3)^2 = x^-4 y^6 จากนั้นหารด้วย x y^-1 ได้ x^(-4-1) y^(6-(-1)) = x^-5 y^7 = y^7/x^5
H6หา n เมื่อ 4^n = 2^20

คำใบ้: เปลี่ยน 4 เป็น 2^2
เฉลย: 4^n = (2^2)^n = 2^(2n) = 2^20 ดังนั้น 2n = 20 และ n = 10
H7จำนวน 2^10 มีค่ากี่หลัก

คำใบ้: คำนวณ 2^10 ก่อน
เฉลย: 2^10 = 1024 จึงมี 4 หลัก
H8จงหา k มากที่สุดที่ทำให้ 2^k หาร 48! ลงตัว

คำใบ้: นับจำนวนตัวประกอบ 2 ใน 48!
เฉลย: k = floor(48/2)+floor(48/4)+floor(48/8)+floor(48/16)+floor(48/32) = 24+12+6+3+1 = 46

แนว สอวน. คอม: เชื่อมกับการคิดแบบโปรแกรมเมอร์

P1ให้ x = 1 แล้วทำซ้ำ 8 รอบ: x = x x 2 ค่าสุดท้ายของ x คือเท่าใด

คำใบ้: เริ่มจาก 1 แล้วคูณ 2 ทั้งหมด 8 ครั้ง
เฉลย: หลัง 8 รอบ ได้ x = 2^8 = 256
P2ข้อมูลเริ่มต้น 3 หน่วย และเพิ่มเป็นสองเท่าทุกวัน หลังผ่านไป 6 วันมีข้อมูลกี่หน่วย

คำใบ้: เพิ่มเป็นสองเท่า 6 ครั้ง จึงคูณด้วย 2^6
เฉลย: 3 x 2^6 = 3 x 64 = 192
P3กำหนด n = 1000 แล้วทำซ้ำ while n >= 2: n = n // 2 จะทำซ้ำกี่รอบ

คำใบ้: นับการหารครึ่งแบบปัดเศษลงจนเหลือ 1
เฉลย: 1000 -> 500 -> 250 -> 125 -> 62 -> 31 -> 15 -> 7 -> 3 -> 1 รวม 9 รอบ
P4หาค่า k น้อยที่สุดที่ทำให้ 2^k > 1000

คำใบ้: เปรียบเทียบ 2^9 และ 2^10
เฉลย: 2^9 = 512 ยังไม่เกิน 1000 แต่ 2^10 = 1024 เกิน 1000 ดังนั้น k = 10
P5หาเศษของ 2^2026 เมื่อหารด้วย 7

คำใบ้: ดูคาบของ 2^n mod 7: 2, 4, 1
เฉลย: 2026 หาร 3 เหลือ 1 จึงเท่ากับตำแหน่งที่ 1 ของคาบ คือ 2

แนวสอบเข้า ม.4: คิดเร็วและระวังช้อยส์หลอก

T1จำนวนใดมากกว่า: 2^30 หรือ 3^20

คำใบ้: เขียนเป็นกำลังที่มีเลขชี้กำลังเท่ากัน
เฉลย: 2^30 = (2^3)^10 = 8^10 และ 3^20 = (3^2)^10 = 9^10 ดังนั้น 3^20 มากกว่า
T2ถ้า x = 2^3 x 3^2 และ y = 2^5 x 3 จงหา ค.ร.น. ของ x และ y

คำใบ้: ค.ร.น. ใช้เลขชี้กำลังที่มากกว่าในแต่ละฐานเฉพาะ
เฉลย: ค.ร.น. = 2^max(3,5) x 3^max(2,1) = 2^5 x 3^2 = 32 x 9 = 288
T3ลดรูป (a^2 b^-3)^-2

คำใบ้: เลขชี้กำลังซ้อนให้คูณกัน
เฉลย: (a^2 b^-3)^-2 = a^-4 b^6 = b^6/a^4
T4แก้สมการ 9^x = 27^(x-1)

คำใบ้: เปลี่ยน 9 และ 27 เป็นฐาน 3
เฉลย: 9^x = 3^(2x) และ 27^(x-1) = 3^(3x-3) จึง 2x = 3x - 3 ได้ x = 3
T5ถ้า x = 1/2 จงหา x^-3 + x^-2

คำใบ้: เลขชี้กำลังลบคือส่วนกลับ
เฉลย: x^-3 = (1/2)^-3 = 8 และ x^-2 = 4 ดังนั้นผลรวม = 12
