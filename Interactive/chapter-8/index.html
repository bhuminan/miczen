เศษส่วนพหุนามและสมการติดรูป

บทนี้ฝึกการจัดรูปเศษส่วนพหุนาม การบวก ลบ คูณ หาร และแก้สมการที่มีตัวแปรอยู่ในตัวส่วน จุดสำคัญคือห้ามลืมเงื่อนไขตัวส่วน และต้องตรวจคำตอบหลังแก้สมการทุกครั้ง

ระดับ ม.ต้นสอวน. คอมสอบเข้า ม.4Interactive + Printable

1. เป้าหมายและคำศัพท์สำคัญ

เป้าหมายการเรียนรู้

  • ระบุค่าที่ทำให้ตัวส่วนเป็นศูนย์และตัดออกได้
  • จัดรูปเศษส่วนพหุนามด้วยการแยกตัวประกอบ
  • บวก ลบ คูณ หารเศษส่วนพหุนามได้ถูกต้อง
  • แก้สมการติดเศษส่วนและตรวจคำตอบเกินได้
  • เชื่อมแนวคิดกับ division by zero และ input validation ในโปรแกรม

2. สูตรและกฎที่ต้องแม่น

หลักสำคัญ: เศษส่วนพหุนามไม่ใช่แค่การตัดทอนให้สั้นลง แต่ต้องรักษาเงื่อนไขของนิพจน์เดิมไว้เสมอ เพราะค่าบางค่าอาจทำให้ตัวส่วนเดิมเป็นศูนย์

ตัวส่วนห้ามเป็นศูนย์

A/B นิยามได้เมื่อ B ≠ 0

ก่อนตัดทอนหรือแก้สมการ ต้องหาเงื่อนไขเดิมเสมอ

ตัดทอนได้เฉพาะตัวประกอบ

(ab)/(ac)=b/c เมื่อ a ≠ 0

ห้ามตัดพจน์ที่อยู่ในผลบวก เช่น (x+2)/x ตัด x ไม่ได้

แยกตัวประกอบก่อนตัดทอน

(x2-1)/(x-1)=x+1

เพราะ x^2-1=(x-1)(x+1) และต้องมี x != 1

คูณเศษส่วนพหุนาม

(A/B)(C/D)=AC/BD

หลังคูณควรแยกตัวประกอบเพื่อตัดทอน

หารเศษส่วนพหุนาม

(A/B) ÷ (C/D) = (A/B)(D/C)

ต้องเพิ่มเงื่อนไขว่า C/D ต้องไม่เป็นศูนย์ด้วย

บวก/ลบเศษส่วน

A/B + C/D = (AD+BC)/BD

ทำตัวส่วนร่วมก่อน แล้วค่อยรวมเศษ

แก้สมการติดเศษส่วน

หาเงื่อนไข -> คูณด้วยตัวส่วนร่วม -> แก้ -> ตรวจคำตอบ

ขั้นตรวจคำตอบสำคัญมาก เพราะอาจเกิดคำตอบเกิน

รูปที่ตัดแล้วไม่เท่ากันทุกจุด

(x2-1)/(x-1) กับ x+1 ต่างกันที่ x=1

ทางคณิตศาสตร์ต้องจำเงื่อนไขเดิมไว้

3. ตัวอย่างพร้อมวิธีคิดทีละขั้น

ตัวอย่างที่ 1: หาเงื่อนไขก่อนจัดรูป

โจทย์: จัดรูป (x2-9)/(x-3)

  1. เงื่อนไขเดิม: x-3 ≠ 0 ดังนั้น x ≠ 3
  2. แยกตัวประกอบ x2-9=(x-3)(x+3)
  3. ตัด x-3 ได้ x+3 แต่ต้องคงเงื่อนไข x ≠ 3

ตอบ: x+3, x ≠ 3

ตัวอย่างที่ 2: บวกเศษส่วนพหุนาม

โจทย์: จัดรูป 1/x + 1/(x+2)

  1. ตัวส่วนร่วมคือ x(x+2)
  2. 1/x = (x+2)/(x(x+2)) และ 1/(x+2)=x/(x(x+2))
  3. รวมเศษได้ (2x+2)/(x(x+2))

ตอบ: (2x+2)/(x(x+2))

ตัวอย่างที่ 3: แก้สมการติดเศษส่วน

โจทย์: แก้สมการ (x+2)/(x-1)=2

  1. ตั้งเงื่อนไข x ≠ 1
  2. คูณทั้งสองข้างด้วย x-1 ได้ x+2=2x-2
  3. ย้ายข้างได้ x=4 และไม่ผิดเงื่อนไข

ตอบ: x=4

ตัวอย่างที่ 4: คำตอบเกินจากการตัดทอน

โจทย์: แก้สมการ (x2-1)/(x-1)=2

  1. เงื่อนไขเดิม x ≠ 1
  2. ตัดทอนแล้วได้ x+1=2 จึงได้ x=1
  3. แต่ x=1 ผิดเงื่อนไขเดิม จึงไม่มีคำตอบ

ตอบ: ไม่มีคำตอบ

4. จุดหลอกข้อสอบที่ต้องระวัง

ห้ามตัดพจน์ที่เป็นผลบวก
(x+2)/x ไม่สามารถตัด x แล้วเหลือ 1+2 ได้
ต้องหาเงื่อนไขก่อนตัดทอน
ถ้าตัดแล้วลืมเงื่อนไข คำตอบอาจกว้างเกินจริง
สมการติดเศษส่วนต้องตรวจคำตอบ
ค่าที่ทำให้ตัวส่วนเดิมเป็นศูนย์ต้องถูกตัดทิ้งเสมอ
หารเศษส่วนต้องกลับเศษเป็นส่วน
A/B ÷ C/D = A/B × D/C ไม่ใช่ A/B × C/D
ตัวส่วนร่วมไม่ใช่แค่คูณมั่ว
ควรใช้ตัวประกอบร่วมให้น้อยที่สุดเพื่อลดความผิดพลาด
รูปที่ดูเหมือนเท่ากัน อาจต่างที่เงื่อนไข
(x2-1)/(x-1) และ x+1 ไม่เท่ากันที่ x=1

5. มุมคิดแบบโปรแกรมเมอร์

บทนี้เกี่ยวข้องโดยตรงกับการตรวจ input ก่อนหาร เพราะคอมพิวเตอร์ไม่ยอมให้หารด้วยศูนย์ในความหมายปกติ ดังนั้นการหาเงื่อนไขของตัวแปรจึงเหมือนการเขียน guard condition ก่อนคำนวณ

แนวคิดการใช้แบบโปรแกรมเมอร์
division by zeroโปรแกรมจะ error หรือให้ผลลัพธ์พิเศษเมื่อหารด้วยศูนย์ จึงต้องเช็กตัวส่วนก่อน
domain restrictionเหมือน if-condition ที่กำหนดว่าค่าใดใช้ได้หรือใช้ไม่ได้
simplificationลดรูปนิพจน์ก่อนคำนวณเพื่อทำให้ algorithm สั้นลงและเสี่ยง overflow น้อยลง
valid input countโจทย์นับจำนวนค่าที่ทำให้ตัวส่วนไม่เป็นศูนย์คือการกรองข้อมูลตามเงื่อนไข
สังเกต: ในการเขียนโปรแกรม การลดรูปสูตรอาจทำให้คำนวณเร็วขึ้น แต่ห้ามลดรูปจนลืมกรณีต้องห้าม เช่น x=1 ใน (x^2-1)/(x-1)
