อสมการ

บทนี้ทำให้นักเรียนเข้าใจว่า “คำตอบ” อาจเป็นช่วงของจำนวน ไม่ใช่ค่าเดียว พร้อมฝึกอสมการเชิงเส้น อสมการกำลังสอง และการนับจำนวนเต็มตามเงื่อนไขที่พบในโจทย์คอมพิวเตอร์

ระดับ ม.ต้นสอวน. คอมสอบเข้า ม.4Interactive + Printable

1. เป้าหมายและคำศัพท์สำคัญ

เป้าหมายการเรียนรู้

  • เข้าใจว่าอสมการคือการบอกช่วงค่าที่เป็นไปได้ ไม่ใช่หาค่าเดียวเสมอไป
  • แก้อสมการเชิงเส้นได้อย่างถูกต้อง โดยเฉพาะกรณีคูณหรือหารด้วยจำนวนลบ
  • เขียนคำตอบเป็นช่วงและอ่านจากเส้นจำนวนได้
  • แก้อสมการกำลังสองด้วยการแยกตัวประกอบและเส้นจำนวน
  • นับจำนวนเต็มที่เข้าเงื่อนไข เพื่อนำไปใช้ในโจทย์เชิงโปรแกรม

2. กฎสำคัญที่ต้องแม่น

หัวใจของบทนี้: อสมการไม่ได้ถามหาคำตอบเดียวเสมอไป แต่ถามหา “ช่วงของค่า” ที่ทำให้ประโยคเป็นจริง กฎที่พลาดบ่อยที่สุดคือ เมื่อคูณหรือหารด้วยจำนวนลบ ต้องกลับเครื่องหมายทันที

บวกหรือลบจำนวนเดียวกัน

a < b -> a+c < b+c

เครื่องหมายไม่เปลี่ยน

คูณหรือหารด้วยจำนวนบวก

a < b, c>0 -> ac < bc

เครื่องหมายไม่เปลี่ยน

คูณหรือหารด้วยจำนวนลบ

a < b, c<0 -> ac > bc

เครื่องหมายกลับทิศ

อสมการแบบช่วง

-2 ≤ x < 5

แปลว่า x ตั้งแต่ -2 ขึ้นไป แต่ต้องน้อยกว่า 5

จุดปลายเปิดและปิด

<, > = วงกลมโปร่ง / ≤, ≥ = วงกลมทึบ

ใช้เมื่อต้องวาดเส้นจำนวน

อสมการกำลังสอง

(x-a)(x-b) > 0

หาจุดวิกฤต แล้วดูเครื่องหมายในแต่ละช่วง

3. ตัวอย่างพร้อมวิธีคิดทีละขั้น

ตัวอย่างที่ 1: อสมการเชิงเส้นพื้นฐาน

โจทย์: แก้อสมการ 3x - 5 ≤ 10

  1. บวก 5 ทั้งสองข้าง: 3x ≤ 15
  2. หารด้วย 3 ซึ่งเป็นจำนวนบวก เครื่องหมายไม่กลับ

คำตอบ: x ≤ 5

ตัวอย่างที่ 2: กรณีต้องกลับเครื่องหมาย

โจทย์: แก้อสมการ -2x + 7 > 15

  1. ลบ 7 ทั้งสองข้าง: -2x > 8
  2. หารด้วย -2 ต้องกลับเครื่องหมาย

คำตอบ: x < -4

ตัวอย่างที่ 3: อสมการแบบช่วง

โจทย์: แก้อสมการ -2 ≤ 3x + 1 < 10

  1. ลบ 1 ทุกส่วน: -3 ≤ 3x < 9
  2. หารด้วย 3 ทุกส่วน

คำตอบ: -1 ≤ x < 3

ตัวอย่างที่ 4: อสมการกำลังสอง

โจทย์: แก้อสมการ (x-2)(x+3) ≤ 0

  1. จุดวิกฤตคือ x=2 และ x=-3
  2. ผลคูณไม่เกินศูนย์ หมายถึงเป็นลบหรือศูนย์
  3. ระหว่างราก ผลคูณเป็นลบ และรวมปลายเพราะมีเครื่องหมาย =

คำตอบ: -3 ≤ x ≤ 2

ตัวอย่างผิดที่ต้องระวัง

จาก -3x < 9 หากเขียน x < -3 ถือว่าผิด เพราะเมื่อหารด้วย -3 ต้องกลับเครื่องหมาย คำตอบที่ถูกคือ x > -3

4. จุดหลอกข้อสอบ

1) หารด้วยจำนวนลบแล้วลืมกลับเครื่องหมาย

นี่คือจุดเสียคะแนนอันดับแรกของบทอสมการ

2) แก้อสมการกำลังสองเหมือนสมการ

สมการหาค่า x ที่ทำให้เท่ากับศูนย์ แต่อสมการต้องเลือกช่วงที่ทำให้เครื่องหมายถูกต้อง

3) ลืมรวมจุดปลาย

เครื่องหมาย ≤ และ ≥ ต้องรวมจุดปลาย ส่วน < และ > ไม่รวม

4) คูณด้วยตัวแปรโดยไม่รู้เครื่องหมาย

ถ้าตัวแปรอาจเป็นบวกหรือลบ การคูณทั้งสองข้างอาจทำให้เครื่องหมายผิด ต้องแยกกรณี

5. มุมคิดแบบโปรแกรมเมอร์

อสมการคือพื้นฐานของเงื่อนไขในโปรแกรม เช่น if x >= 0 and x < 100 การนับจำนวนเต็มในช่วงและการตรวจเงื่อนไขเป็นทักษะที่ใช้ตรงกับโจทย์ สอวน. คอม

ช่วงค่าในโปรแกรม

2 ≤ x < 9 สำหรับจำนวนเต็ม มีค่า 2,3,4,5,6,7,8 รวม 7 ค่า

เงื่อนไขหลายข้อ

คำว่า “และ” คือค่าต้องผ่านทุกเงื่อนไข เช่น x>0 and x<10

การนับด้วย loop

โจทย์ถามจำนวนเต็มที่เข้าเงื่อนไข สามารถคิดเหมือนวนลูปตรวจทีละค่าได้ แต่ในการสอบควรหาวิธีนับเร็ว

Binary search กับกำลังสอง

การหา x มากที่สุดที่ทำให้ x2 ≤ n คือแนวคิดเดียวกับการหา floor square root

ระดับยาก: อสมการกำลังสองและกรณีพิเศษ

H1
จงแก้อสมการ (x - 2)(x + 5) > 0

Hint: หาจุดวิกฤต -5 และ 2 แล้วดูช่วงที่ผลคูณเป็นบวก
เฉลย: ผลคูณเป็นบวกเมื่อทั้งสองตัวประกอบมีเครื่องหมายเหมือนกัน จึงได้ x<-5 หรือ x>2
คำตอบ: x<-5 หรือ x>2
H2
จงแก้อสมการ (x - 3)(x + 1) ≤ 0

Hint: ผลคูณไม่เกินศูนย์คือช่วงระหว่างราก รวมปลายเพราะมี =
เฉลย: ได้ -1≤x≤3
คำตอบ: -1≤x≤3
H3
จงแก้อสมการ x2 - 9 < 0

Hint: แยกเป็น (x-3)(x+3)<0
เฉลย: ผลคูณเป็นลบระหว่างราก จึงได้ -3<x<3
คำตอบ: -3<x<3
H4
จงแก้อสมการ x2 - 4x + 3 ≥ 0

Hint: แยกเป็น (x-1)(x-3)≥0
เฉลย: พาราโบลาเปิดขึ้น เลือกช่วงนอกและรวมปลาย ได้ x≤1 หรือ x≥3
คำตอบ: x≤1 หรือ x≥3
H5
จงแก้อสมการ x2 + 2x + 1 > 0

Hint: จัดเป็นกำลังสองสมบูรณ์
เฉลย: (x+1)2>0 เป็นจริงทุกค่า ยกเว้น x=-1
คำตอบ: x≠-1
H6
จงแก้อสมการ x2 + 1 < 0

Hint: กำลังสองไม่ติดลบ และบวก 1 แล้วยิ่งมากกว่า 0
เฉลย: x2≥0 จึงมี x2+1≥1 ไม่มีทางน้อยกว่า 0
คำตอบ: ไม่มีคำตอบ
H7
จงแก้อสมการ (x - 2)2 ≤ 9

Hint: ถ้า A2≤9 แปลว่า -3≤A≤3
เฉลย: -3≤x-2≤3 จึงได้ -1≤x≤5
คำตอบ: -1≤x≤5
H8
จำนวนเต็ม x ที่ทำให้ x2 < 50 มีกี่ค่า

Hint: หา x ที่อยู่ระหว่าง -sqrt(50) และ sqrt(50)
เฉลย: จำนวนเต็มที่ใช้ได้คือ -7 ถึง 7 รวม 15 ค่า
คำตอบ: 15
