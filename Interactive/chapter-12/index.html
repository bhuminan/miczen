การหารลงตัวและเศษเหลือ

บทนี้ทำให้นักเรียนเข้าใจการเขียนจำนวนในรูป a = bq + r และใช้เศษเหลือเพื่อแก้โจทย์นับจำนวน ตรวจเงื่อนไข และวิเคราะห์รูปแบบซ้ำแบบที่พบใน สอวน. คอม

ระดับ ม.ต้นทฤษฎีจำนวนสอวน. คอมInteractive + Printable

1. คำศัพท์สำคัญ

บทนี้ใช้ภาษาคณิตศาสตร์ที่เชื่อมกับการเขียนโปรแกรมโดยตรง โดยเฉพาะคำว่า ผลหาร และ เศษเหลือ

2. แนวคิดและกฎที่ต้องจำ

หลักการหารแบบมีเศษ

a = bq + r, 0 ≤ r < b

เมื่อ b เป็นจำนวนเต็มบวก q คือผลหาร และ r คือเศษเหลือ

หารลงตัว

b | a ↔ a = bk

อ่านว่า b หาร a ลงตัว หมายถึง a เป็นพหุคูณของ b

จำนวนคู่ / จำนวนคี่

even = 2k, odd = 2k+1

จำนวนคู่หารด้วย 2 เหลือ 0 ส่วนจำนวนคี่หารด้วย 2 เหลือ 1

เศษเหลือในโปรแกรม

a // b = q, a % b = r

ใน Python เครื่องหมาย // ใช้หาผลหารปัดลง และ % ใช้หาเศษเหลือ

กฎหารลงตัวที่ควรรู้

หารด้วยวิธีตรวจเร็ว
2หลักหน่วยเป็น 0,2,4,6,8
3ผลรวมเลขโดดหารด้วย 3 ลงตัว
4เลขสองหลักท้ายหารด้วย 4 ลงตัว
5หลักหน่วยเป็น 0 หรือ 5
9ผลรวมเลขโดดหารด้วย 9 ลงตัว
10หลักหน่วยเป็น 0

3. ตัวอย่างพร้อมวิธีคิดทีละขั้น

ตัวอย่างที่ 1: หาผลหารและเศษ

โจทย์: เมื่อหาร 53 ด้วย 7 ได้ผลหารและเศษเท่าใด

  1. หาพหุคูณของ 7 ที่ไม่เกิน 53: 7×7 = 49
  2. เศษคือ 53 - 49 = 4

คำตอบ: 53 = 7×7 + 4 ดังนั้นผลหาร 7 เศษ 4

ตัวอย่างที่ 2: ใช้กฎหารลงตัว

โจทย์: 381 หารด้วย 3 ลงตัวหรือไม่

  1. ผลรวมเลขโดดคือ 3+8+1 = 12
  2. 12 หารด้วย 3 ลงตัว

คำตอบ: 381 หารด้วย 3 ลงตัว

ตัวอย่างที่ 3: นับพหุคูณในช่วง

โจทย์: ตั้งแต่ 1 ถึง 100 มีจำนวนที่หารด้วย 6 ลงตัวกี่จำนวน

  1. จำนวนเหล่านั้นคือ 6,12,18,...,96
  2. ใช้สูตร floor(100/6)

คำตอบ: 16 จำนวน

ตัวอย่างที่ 4: บวกเศษเหลือ

โจทย์: ถ้า n หารด้วย 5 เหลือ 3 แล้ว n+9 หารด้วย 5 เหลือเท่าใด

  1. ดูเฉพาะเศษ: 3+9 = 12
  2. 12 หารด้วย 5 เหลือ 2

คำตอบ: เหลือ 2

4. จุดหลอกข้อสอบ

1) เศษต้องน้อยกว่าตัวหาร

เช่น 29 = 4×6 + 5 ยังไม่ถูกในรูปมาตรฐาน เพราะเศษ 5 มากกว่าตัวหาร 4 ต้องเขียนเป็น 29 = 4×7 + 1

2) หารลงตัวแปลว่าเศษเป็นศูนย์

ถ้า a หารด้วย b ลงตัว ต้องได้เศษ 0 ไม่ใช่แค่หารแล้วใกล้เคียงจำนวนเต็ม

3) การบวกเศษต้องลดกลับมาอยู่ในช่วง

ถ้าเศษรวมเป็น 12 เมื่อหารด้วย 5 ต้องลดเหลือ 2

4) ระวังโจทย์ถาม “หารด้วย” กับ “หาร”

“3 หาร 12 ลงตัว” หมายถึง 12 ถูกหารด้วย 3 ได้ลงตัว ไม่ใช่ 3/12

5. มุมคิดแบบโปรแกรมเมอร์

การหารลงตัวและเศษเหลือเป็นหัวใจของการเขียนโปรแกรมพื้นฐาน เช่น ตรวจเลขคู่ ตรวจรอบของรูปแบบซ้ำ นับพหุคูณ และตรวจจำนวนเฉพาะ

ตรวจเลขคู่

n % 2 == 0 แปลว่า n เป็นจำนวนคู่

ตรวจหารลงตัว

n % d == 0 แปลว่า d หาร n ลงตัว

นับจำนวนรอบ

จำนวนพหุคูณของ d ตั้งแต่ 1 ถึง n คือ floor(n/d)

รูปแบบวนซ้ำ

ถ้ารูปแบบวนทุก 4 ครั้ง ให้ดูค่า k % 4 เพื่อรู้ตำแหน่งในรอบ
