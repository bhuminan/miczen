ค่าสัมบูรณ์ (Absolute Value)

บทนี้ทำให้ค่าสัมบูรณ์ไม่ใช่แค่ “เปลี่ยนลบเป็นบวก” แต่เป็นแนวคิดเรื่องระยะห่าง เงื่อนไข และการนับจำนวนเต็ม ซึ่งใช้จริงในโจทย์คณิตศาสตร์แข่งขันและการเขียนโปรแกรม

ระดับ ม.ต้นสอวน. คอมสอบเข้า ม.4Interactive + Printable

1. เป้าหมายและคำศัพท์สำคัญ

เป้าหมายการเรียนรู้

  • เข้าใจค่าสัมบูรณ์ในฐานะระยะห่างจาก 0
  • คำนวณนิพจน์ที่มีเครื่องหมาย | | ได้ถูกลำดับ
  • แก้สมการและอสมการค่าสัมบูรณ์พื้นฐานได้
  • นับจำนวนเต็มที่อยู่ในช่วงจากเงื่อนไขค่าสัมบูรณ์ได้
  • เชื่อม abs(a-b) กับแนวคิด absolute difference ในโปรแกรม

2. สูตรและกฎที่ต้องแม่น

หลักสำคัญ: ค่าสัมบูรณ์คือ “ระยะห่าง” ดังนั้นผลลัพธ์จึงไม่ติดลบเสมอ และสมการ/อสมการหลายข้อควรแปลเป็นภาพบนเส้นจำนวนก่อนเริ่มคำนวณ

นิยามค่าสัมบูรณ์
|a| = a เมื่อ a >= 0 และ |a| = -a เมื่อ a < 0
มองเป็นระยะห่างจาก 0 บนเส้นจำนวน
ผลลัพธ์ไม่ติดลบ
|a| >= 0 เสมอ
ดังนั้น |x| = จำนวนลบ จะไม่มีคำตอบ
สมมาตรของเครื่องหมาย
|-a| = |a|
จำนวนที่อยู่ซ้าย/ขวาของ 0 เท่ากัน มีค่าสัมบูรณ์เท่ากัน
รากที่สองกับค่าสัมบูรณ์
sqrt(a^2) = |a|
สำคัญมากในบทกรณฑ์และสมการ
ผลคูณและผลหาร
|ab| = |a||b| และ |a/b| = |a|/|b| เมื่อ b != 0
ใช้แยกค่าสัมบูรณ์ของพจน์คูณและหาร
ระยะห่างของสองจำนวน
ระยะห่างระหว่าง a และ b คือ |a-b|
ใช้กับเส้นจำนวน โปรแกรม และโจทย์เปรียบเทียบ
สมการพื้นฐาน
|x-a| = r ให้ x = a-r หรือ x = a+r เมื่อ r >= 0
แปลว่า x อยู่ห่างจาก a เท่ากับ r
อสมการพื้นฐาน
|x-a| <= r ให้ a-r <= x <= a+r เมื่อ r >= 0
แปลว่า x อยู่ในช่วงใกล้ a ไม่เกิน r

3. ตัวอย่างพร้อมวิธีคิดทีละขั้น

ตัวอย่างที่ 1: คำนวณค่าสัมบูรณ์ซ้อน

โจทย์: คำนวณ |4 - |2 - 9||

ทำด้านในก่อน: |2 - 9| = |-7| = 7
แทนกลับได้ |4 - 7|
|4 - 7| = |-3| = 3
คำตอบ: 3
ตัวอย่างที่ 2: สมการค่าสัมบูรณ์

โจทย์: แก้สมการ |x - 5| = 3

แปลว่า x อยู่ห่างจาก 5 เป็นระยะ 3
กรณีขวา: x = 5 + 3 = 8
กรณีซ้าย: x = 5 - 3 = 2
คำตอบ: x = 2 หรือ 8
ตัวอย่างที่ 3: อสมการค่าสัมบูรณ์

โจทย์: แก้อสมการ |x + 2| <= 4

เขียนเป็น |x - (-2)| <= 4
แปลว่า x อยู่ห่างจาก -2 ไม่เกิน 4
-6 <= x <= 2
คำตอบ: -6 <= x <= 2
ตัวอย่างที่ 4: คิดแบบโปรแกรมเมอร์

โจทย์: นับจำนวนเต็ม x ที่ทำให้ abs(x-10) <= 2

เงื่อนไขคือ 10-2 <= x <= 10+2
ดังนั้น 8 <= x <= 12
จำนวนเต็มคือ 8,9,10,11,12
คำตอบ: 5 ค่า

4. จุดหลอกข้อสอบที่ต้องระวัง

|x| = 5 ไม่ได้มีคำตอบเดียว
คำตอบคือ x = 5 หรือ x = -5 เพราะสองจุดห่างจาก 0 เท่ากัน
-|a| อาจติดลบได้
เช่น -|-6| = -6 เพราะลบอยู่ข้างนอกเครื่องหมายค่าสัมบูรณ์
|a-b| = |b-a|
ระยะห่างไม่สนทิศทาง จึงสลับลำดับได้
|x| = จำนวนลบ ไม่มีคำตอบ
เพราะค่าสัมบูรณ์ไม่มีทางน้อยกว่า 0
อสมการ < กับ > คนละทิศทางของช่วง
|x-a| < r เป็นช่วงกลาง แต่ |x-a| > r เป็นช่วงนอกสองด้าน
อย่าตัดเครื่องหมาย | | ทิ้งโดยไม่แยกกรณี
นิพจน์ข้างในอาจบวกหรือลบ ต้องดูเงื่อนไข

5. มุมคิดแบบโปรแกรมเมอร์

ในภาษาโปรแกรมส่วนใหญ่จะมีฟังก์ชัน abs() สำหรับหาค่าสัมบูรณ์ เช่น abs(-7)=7 และ abs(a-b) ใช้วัดระยะห่างระหว่างสองจำนวนโดยไม่สนว่าค่าใดมากกว่า

แนวคิดคณิตศาสตร์เชื่อมกับคอมพิวเตอร์
|a-b|absolute difference หรือความต่างแบบไม่ติดลบ
|x-target| <= rตรวจว่าค่า x อยู่ในช่วงที่ยอมรับได้หรือไม่
|x-y| == 0ตรวจว่าสองค่ามีค่าเท่ากัน
นับจำนวนเต็มในช่วงใช้กับ loop และ condition
สังเกต: เงื่อนไข abs(score-target) <= 5 มีความหมายว่า score อยู่ในช่วง target-5 ถึง target+5 ไม่ใช่แค่ score น้อยกว่า target

ระดับปานกลาง: สมการค่าสัมบูรณ์และระยะบนเส้นจำนวน

M1แก้สมการ |x| = 8 โดยตอบเป็นจำนวนจริงทั้งหมด

คำใบ้: |x| = c ให้ x = c หรือ x = -c เมื่อ c > 0
เฉลย: คำตอบคือ x = 8 หรือ x = -8
M2แก้สมการ |x| = 0

คำใบ้: มีเพียงจำนวนเดียวที่ห่างจาก 0 เป็น 0
เฉลย: คำตอบคือ x = 0
M3สมการ |x| = -3 มีคำตอบกี่คำตอบ

คำใบ้: ค่าสัมบูรณ์ไม่มีทางติดลบ
เฉลย: |x| >= 0 เสมอ จึงไม่มีคำตอบ
M4แก้สมการ |x - 4| = 6

คำใบ้: ระยะห่างจาก 4 เท่ากับ 6
เฉลย: x - 4 = 6 หรือ x - 4 = -6 จึงได้ x = 10 หรือ x = -2
M5แก้สมการ |2x - 1| = 7

คำใบ้: แยกเป็น 2x-1 = 7 หรือ 2x-1 = -7
เฉลย: 2x - 1 = 7 ได้ x = 4 และ 2x - 1 = -7 ได้ x = -3
M6แก้สมการ |3x + 2| = 11

คำใบ้: แยกสองกรณี
เฉลย: 3x+2=11 ได้ x=3 และ 3x+2=-11 ได้ x=-13/3
M7หาค่า x ที่เป็นจำนวนเต็มทั้งหมดซึ่งทำให้ |x - 2| <= 3

คำใบ้: แปลว่า x อยู่ห่างจาก 2 ไม่เกิน 3
เฉลย: -3 <= x-2 <= 3 จึง -1 <= x <= 5 จำนวนเต็มคือ -1,0,1,2,3,4,5
M8มีจำนวนเต็ม x กี่จำนวนที่ทำให้ |x - 2| <= 3

คำใบ้: จากข้อก่อน x ตั้งแต่ -1 ถึง 5
เฉลย: จำนวนเต็มตั้งแต่ -1 ถึง 5 มี 5 - (-1) + 1 = 7 จำนวน
M9แก้อสมการ |x| < 5 โดยตอบเป็นช่วง

คำใบ้: ระยะห่างจาก 0 น้อยกว่า 5
เฉลย: |x| < 5 เท่ากับ -5 < x < 5
M10แก้อสมการ |x - 1| >= 4 โดยตอบเป็นช่วง

คำใบ้: ห่างจาก 1 ตั้งแต่ 4 ขึ้นไป
เฉลย: x-1 <= -4 หรือ x-1 >= 4 จึง x <= -3 หรือ x >= 5

ระดับยาก: เงื่อนไขซ่อน การนับจำนวนเต็ม และพีชคณิต

H1หาค่า |x - 3| + |x + 2| เมื่อ x = 1

คำใบ้: แทนค่า x ก่อน
เฉลย: |1-3| + |1+2| = |-2| + |3| = 2 + 3 = 5
H2หาค่า x ที่ทำให้ |x - 3| + |x + 2| มีค่าน้อยที่สุด และค่าต่ำสุดคือเท่าใด ตอบรูป xช่วง;ค่า

คำใบ้: ผลรวมระยะจาก x ไปยัง 3 และ -2 น้อยที่สุดเมื่อ x อยู่ระหว่างสองจุด
เฉลย: สำหรับ x อยู่ในช่วง [-2,3] ผลรวมระยะไปยังปลายทั้งสองเท่ากับ 3 - (-2) = 5 ซึ่งเป็นค่าต่ำสุด
H3แก้สมการ |x - 1| = |2x + 3|

คำใบ้: ถ้า |A|=|B| แล้ว A=B หรือ A=-B
เฉลย: กรณี 1: x-1=2x+3 ได้ x=-4. กรณี 2: x-1=-(2x+3) ได้ 3x=-2 จึง x=-2/3
H4มีจำนวนเต็ม x กี่จำนวนที่ทำให้ |2x - 5| < 11

คำใบ้: เปลี่ยนเป็นอสมการสองข้างแล้วนับจำนวนเต็ม
เฉลย: -11 < 2x - 5 < 11 จึง -6 < 2x < 16 หรือ -3 < x < 8 จำนวนเต็มคือ -2,-1,0,1,2,3,4,5,6,7 มี 10 จำนวน
H5แก้สมการ |x + 1| + |x - 4| = 5

คำใบ้: ผลรวมระยะจาก x ไป -1 และ 4 เท่ากับระยะระหว่างสองจุด
เฉลย: ระยะระหว่าง -1 และ 4 คือ 5 ถ้า x อยู่ระหว่าง -1 ถึง 4 ผลรวมระยะเท่ากับ 5 พอดี คำตอบคือ -1 <= x <= 4
H6แก้สมการ |x + 1| + |x - 4| = 7

คำใบ้: อยู่นอกช่วง [-1,4] เท่านั้นจึงเพิ่มระยะรวม
เฉลย: ถ้า x < -1 จะได้ -(x+1) + (4-x) = 7 จึง -2x+3=7 ได้ x=-2. ถ้า x > 4 จะได้ x+1+x-4=7 จึง 2x-3=7 ได้ x=5
H7หาจำนวนเต็ม x ทั้งหมดที่ทำให้ |x + 3| < |x - 5|

คำใบ้: จุดที่อยู่ใกล้ -3 มากกว่า 5 จะอยู่ด้านซ้ายของจุดกึ่งกลาง
เฉลย: เปรียบเทียบระยะถึง -3 และ 5 จุดกึ่งกลางคือ 1 ดังนั้น |x+3| < |x-5| เมื่อ x < 1
H8หาค่ามากที่สุดของ |x - 2| เมื่อ x เป็นจำนวนเต็มและ -3 <= x <= 7

คำใบ้: ค่าสูงสุดเกิดที่ปลายช่วงซึ่งห่างจาก 2 มากที่สุด
เฉลย: ตรวจปลายช่วง: |-3-2|=5 และ |7-2|=5 ดังนั้นค่าสูงสุดคือ 5

แนว สอวน. คอม: absolute difference, condition และการนับ

P1ในโปรแกรม abs(a-b) ใช้วัดอะไรระหว่าง a และ b

คำใบ้: ผลลัพธ์ไม่มีเครื่องหมายลบ
เฉลย: abs(a-b) คือระยะห่างหรือความต่างแบบไม่สนทิศทางระหว่าง a และ b
P2ถ้า a = -7 และ b = 4 ค่า abs(a-b) เท่ากับเท่าใด

คำใบ้: คำนวณ a-b ก่อน
เฉลย: a-b = -7-4 = -11 ดังนั้น abs(a-b)=11
P3มีจำนวนเต็ม x ตั้งแต่ 1 ถึง 20 กี่จำนวนที่ทำให้ abs(x-10) <= 3

คำใบ้: x ต้องอยู่ในช่วงใกล้ 10 ไม่เกิน 3
เฉลย: 7 <= x <= 13 มีจำนวนเต็ม 7 จำนวน
P4เงื่อนไข abs(x-y) == 0 หมายความว่าอย่างไร

คำใบ้: ระยะห่างเป็นศูนย์เมื่อสองค่าตรงกัน
เฉลย: abs(x-y)=0 ก็ต่อเมื่อ x-y=0 ดังนั้น x=y
P5ถ้า loop ตรวจ i ตั้งแต่ -5 ถึง 5 และนับเมื่อ abs(i) <= 2 จะนับได้กี่ค่า

คำใบ้: ค่าที่ผ่านคือ -2 ถึง 2
เฉลย: i = -2,-1,0,1,2 มี 5 ค่า
P6ถ้าใช้เงื่อนไข abs(score-target) <= 5 โดย target = 80 คะแนน score ต่ำสุดและสูงสุดที่ผ่านคือเท่าใด ตอบ ต่ำสุด,สูงสุด

คำใบ้: คะแนนต้องอยู่ห่างจาก 80 ไม่เกิน 5
เฉลย: 80-5 <= score <= 80+5 จึงผ่านตั้งแต่ 75 ถึง 85
