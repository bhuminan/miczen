1. เป้าหมายและคำศัพท์สำคัญ

เป้าหมายการเรียนรู้

  • เข้าใจว่า √(a) คือรากที่สองหลักที่ไม่ติดลบ

  • เปรียบเทียบและประมาณค่ารากที่สองได้
  • ใช้แนวคิด floor square root กับโจทย์คอมพิวเตอร์ได้

3. สูตรและกฎที่ต้องแม่น

หลักสำคัญ: √(a) ให้ค่าที่ไม่ติดลบเสมอ ส่วนสมการ x^2=a อาจมีสองคำตอบ คือ x=±√(a) เมื่อ a>0

ความหมายของรากที่สอง
√(a) คือจำนวนไม่ติดลบที่ยกกำลังสองแล้วได้ a
นิยามนี้ใช้เมื่อ a >= 0 ในจำนวนจริง
รากที่สองกับกำลังสอง
(√(a))^2 = a, เมื่อ a >= 0
รากที่สองและกำลังสองหักล้างกันได้ภายใต้เงื่อนไข
รากของกำลังสอง
√(a^2) = |a|
สำคัญมาก: ถ้า a เป็นลบ ผลลัพธ์ยังต้องไม่ติดลบ
กฎการคูณ
√(ab) = √(a)√(b), เมื่อ a,b >= 0
ใช้แยกตัวประกอบกำลังสองสมบูรณ์ออกนอกราก
กฎการหาร
√(a/b) = √(a)/√(b), เมื่อ a >= 0, b > 0
ใช้กับเศษส่วนและการทำตัวส่วนให้ไม่มีราก
การจัดรูปกรณฑ์
√(k^2m) = k√(m), เมื่อ k >= 0
ดึงตัวประกอบที่เป็นกำลังสองสมบูรณ์ออกมา
พจน์คล้ายของกรณฑ์
a√(m)+b√(m)=(a+b)√(m)
บวกลบได้เฉพาะเมื่อส่วนในรากเหมือนกันหลังจัดรูป
การประมาณค่า
ถ้า n^2 <= a < (n+1)^2 แล้ว floor(√(a)) = n
เป็นพื้นฐานของ integer square root ในคอมพิวเตอร์

4. ตัวอย่างพร้อมวิธีคิดทีละขั้น

ตัวอย่างที่ 1: จัดรูปกรณฑ์

โจทย์: จัดรูป √(180)

แยก 180 = 36 x 5
√(180) = √(36 x 5)
√(36)=6 ดังนั้นคำตอบคือ 6√(5)
คำตอบ: 6√(5)
ตัวอย่างที่ 2: บวกพจน์กรณฑ์

โจทย์: ลดรูป √(75) - √(27) + √(12)

√(75)=5√(3)
√(27)=3√(3)
√(12)=2√(3)
รวมสัมประสิทธิ์: 5 - 3 + 2 = 4
คำตอบ: 4√(3)
ตัวอย่างที่ 3: ระวัง √(a^2)

โจทย์: คำนวณ √((-11)^2)

ใช้สูตร √(a^2)=|a|
a=-11 จึงได้ |-11|
ผลลัพธ์คือ 11 ไม่ใช่ -11
คำตอบ: 11
ตัวอย่างที่ 4: Floor square root

โจทย์: หา floor(√(500))

22^2 = 484
23^2 = 529
ดังนั้น √(500) อยู่ระหว่าง 22 และ 23
คำตอบ: 22

5. จุดหลอกข้อสอบที่ต้องระวัง

√(a) ไม่ให้คำตอบติดลบ
√(81)=9 ไม่ใช่ ±9 แต่สมการ x^2=81 มีคำตอบ x=±9
√(a^2)=|a| ไม่ใช่ a เสมอ
ถ้า a=-5 จะได้ √((-5)^2)=5
บวกกรณฑ์ต้องเป็นพจน์คล้าย
√(2)+√(3) รวมเป็น √(5) ไม่ได้
ใช้กฎคูณ/หารได้เมื่อค่าข้างในรากไม่ติดลบในจำนวนจริง
ระดับ ม.ต้นควรระวังเงื่อนไข a,b >= 0
การยกกำลังสองสมการอาจสร้างคำตอบเกิน
ต้องตรวจคำตอบกลับเสมอ โดยเฉพาะเมื่อมี √(...) = นิพจน์
การประมาณค่าอย่าปัดมั่ว
√(50) ประมาณ 7.07 เพราะอยู่ใกล้ 49 มากกว่า 64

6. มุมคิดแบบโปรแกรมเมอร์

ในคอมพิวเตอร์ การหาค่า √(n) มักไม่ได้ต้องการค่าทศนิยมเสมอไป หลายโจทย์ต้องการ floor(√(n)) หรือจำนวนเต็มมากที่สุดที่ยกกำลังสองแล้วไม่เกิน n เช่น ใช้ตรวจจำนวนเฉพาะ ตรวจตัวหาร และตรวจ perfect square

แนวคิดคณิตศาสตร์เชื่อมกับคอมพิวเตอร์
floor(√(n))ขอบเขตการวน loop ตรวจตัวหาร
n เป็น perfect square หรือไม่ตรวจว่า k*k == n เมื่อ k=floor(√(n))
ช่วง n^2 <= a < (n+1)^2ใช้ binary search หา integer square root
หลีกเลี่ยง float errorใช้ integer arithmetic เมื่อความถูกต้องสำคัญ
สังเกต: ถ้าต้องตรวจตัวหารของ n ไม่จำเป็นต้องวนถึง n ทั้งหมด วนถึง floor(√(n)) ก็พอ เพราะตัวหารมักมาเป็นคู่ เช่น 36 = 4 x 9
